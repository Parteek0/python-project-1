# 🐍 Snake Water Gun Game

A simple command-line **Snake, Water, Gun** game built using Python. Play against the computer, make your choice, and see who wins!

## 📌 About the Project

This is a beginner-friendly Python project based on the classic Snake, Water, Gun game. The player competes against the computer, which randomly selects one of the three options.

The project helped me practice Python fundamentals, conditional statements, user input handling, and randomization.

## 🎮 Game Rules

- 🐍 Snake drinks Water → **Snake wins**
- 💧 Water damages Gun → **Water wins**
- 🔫 Gun kills Snake → **Gun wins**
- If both choose the same option → **Draw**

## 🛠️ Built With

- **Python 3**
- `random` module

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/Parteek0/snake-water-gun.git
   ```

2. Navigate to the project folder:

   ```bash
   cd snake-water-gun
   ```

3. Run the Python file:

   ```bash
   python main.py
   ```
